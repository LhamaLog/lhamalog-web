# Instruções para agentes

- Leia README.md e docs/planejamento-componentes.md antes de trabalhar. Os arquivos atuais são a fonte de verdade.
- Não execute comandos Git, inclusive consultas. Não crie branches, commits, PRs ou issues e não altere serviços externos.
- Não instale as extensões git ou github do Spec Kit nem habilite eventos automáticos sem uma nova instrução explícita do usuário.
- Trabalhe somente na tarefa ou fase solicitada, em pequenas entregas. Explique o resultado e pare para revisão antes da próxima etapa.
- Preserve a aplicação e as configurações existentes. Não altere autenticação ou integração com Clerk, que são responsabilidade de outra pessoa.
- O planejamento é a visão geral do frontend; spec.md, plan.md e tasks.md detalham uma funcionalidade por vez. Não gere especificações retroativas da aplicação.
- Confira as alterações por leitura e comparação de arquivos, sem Git. Execute o build e as verificações adequadas quando o ambiente estiver preparado; não instale dependências npm automaticamente.
